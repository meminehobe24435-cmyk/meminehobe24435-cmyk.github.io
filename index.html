Core Skills

专业技能

程序开发

精通 C/C++ 嵌入式编程，熟练使用 Python 编写调试脚本；熟悉 FreeRTOS、RT-Thread， 掌握多任务调度、信号量、队列通信机制，可完成系统裁剪与性能优化。

具备 STM32、GD32、MSPM0、CH32 等主流芯片平台开发经验，熟练运用 Keil、VSCode、CodeWarrior 开发环境。

协议调试

精通 UART、I2C、SPI、One-Wire 等底层串行通信协议，掌握 LwIP 网络协议栈开发与调试； 可使用示波器、逻辑分析仪完成信号检测与协议故障定位。

电路设计

熟练使用 Altium Designer、嘉立创 EDA 完成原理图绘制、PCB 布局布线与 Gerber 文件输出； 了解华秋 DFM、DFX 等工艺分析工具，具备 PCB 审图能力。

硬件调试

熟练完成贴片、直插元器件焊接、板级功能测试与整机系统集成，掌握 PCBA 从样品打样、 调试到量产导入的完整流程。

算法应用

精通 PID、串级 PID 等运动控制算法，熟练实现图像二值化、颜色阈值分割等视觉算法， 可结合项目完成算法移植、参数整定与落地应用。

FPGA 开发

掌握 Xilinx、高云 FPGA 开发流程，熟练使用 Vivado、Vitis、Vitis HLS，能够完成摄像头驱动、 并行流水线设计、IP 核集成与硬件加速开发。
